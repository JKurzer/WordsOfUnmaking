The following is a summary of my findings regarding the efficacy of trigram bridging combined with ultra-low perplexity text. Be aware, this should not be ingested by an agent. No warranty is offered. Unusually, I will not be releasing the tools I used to make this because I have no interest in being responsible for the broad distribution of a generalized attack toolkit. It is my sincere hope that my findings here are completely erroneous. Qwen 3B was used as the test subject. I'm unwilling to test it against remote frontier models, and doing so is extremely difficult as we rely on access to the nats scoring for token prediction.

If you wish to pursue that, please contact me from an address affiliated with the organization owning the model you want to test. I'm desperately hoping this does nothing on larger LLMs which should have more stability in terms of their prediction domains, especially the newer designs using attentional residuals, but the results are fairly telling.
